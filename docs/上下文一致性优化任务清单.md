### P0-3：角色锚点标准化 + 提示词6段式重构
- **优先级**：P0
- **借鉴来源**：行业通用 + ArcReel（角色DNA）
- **问题**：`visual_description` 是自由文本，AI理解容易漂移；提示词结构不统一
- **具体内容**：
  - [ ] `script_characters` 表增加结构化锚点字段（face_shape, eye_color, hairstyle, hair_color, outfit, accessories, body_type等）
  - [ ] 角色提取时自动生成标准化视觉锚点（100字内）
  - [ ] 重构 `directorPromptService` 为6段式锁定结构：
    - ① 角色视觉一致性锚点（锁定段，AI不能改）
    - ② 场景一致性锚点（锁定段）
    - ③ 风格一致性锚点（锁定段）
    - ④ 本镜动作+情绪+时序分解（导演级v2.0保留）
    - ⑤ 首尾帧动作弧
    - ⑥ 负面提示词（一致性专项+画质专项）
  - [ ] ①②③段逐字复用，禁止AI优化器修改
  - [ ] 每个提示词生成都必须包含①②③段，缺失则自动补全
- **涉及文件**：
  - 修改：`server/src/services/directorPromptService.ts`（6段式重构）
  - 修改：`server/src/services/aiPromptOptimizerService.ts`（锁定段保护）

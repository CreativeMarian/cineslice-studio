## 1. 首次启动

### 1.1 启动应用

在项目根目录打开终端，执行：

```bash
npm run dev
```

等待终端输出类似以下信息即表示启动成功：

```
========================================
[CineSlice Studio] 前端开发服务器
[CineSlice Studio] 本地访问: http://localhost:5173
[CineSlice Studio] 局域网访问: http://192.168.x.x:5173
========================================
```

### 1.2 打开浏览器

在浏览器中访问 `http://localhost:5173`。

### 1.3 关于登录

CineSlice Studio 支持两种运行模式：

- **本地模式（默认）**：无需注册登录，打开即用。系统自动创建一个 `local_user` 默认用户。
- **服务端模式**：需要注册账号并登录。

如果你是个人用户，使用默认的本地模式即可，跳过登录步骤直接进入主界面。

### 1.4 新手引导

首次进入应用会显示**新手引导（Onboarding）**，按照提示完成以下步骤：

1. 选择你偏好的 AI 模型（文本 / 图像 / 视频 / 音频）
2. 设置默认风格预设
3. 完成引导后进入项目仪表盘

> 新手引导只需完成一次，后续可在「设置」中重新开启。

## 2. 配置 AI 模型

CineSlice Studio 本身不提供 AI 算力，需要你配置自己的 AI 模型 API Key。

### 2.1 进入模型配置页

点击左侧边栏的「**模型配置**」（或访问 `/models`）。

### 2.2 选择模型类型

页面分为四个标签页：

| 标签 | 用途 | 对应流水线阶段 |
|------|------|----------------|
| **文本** | 剧本生成、角色提取、分镜生成等 | 小说上传、剧集拆分、剧本生成、角色设定、场景设定、分镜生成 |
| **图像** | 角色概念图、场景图、关键帧 | 关键帧 |
| **视频** | 镜头视频生成 | 视频生成 |
| **音频** | 配音 / 旁白 TTS | 配音生成 |

### 2.3 添加模型配置

1. 在对应标签页点击「**添加模型**」或从内置模型列表中选择一个。
2. 填写以下信息：
   - **Provider（服务商）**：如 `doubao`、`deepseek`、`openai` 等
   - **Model Name（模型名）**：如 `doubao-seed-1-6`、`gpt-4o`
   - **API Key**：从对应 AI 服务商官网获取的密钥
   - **Endpoint URL（可选）**：自定义接口地址，用于 OpenAI 兼容服务或私有部署
3. 点击「**测试连接**」验证 API Key 是否有效。
4. 测试通过后，点击「**设为默认**」将其设为该类型的默认模型。

### 2.4 支持的内置模型（部分）

**文本模型**：豆包 Seed 1.6 / 1.5 Pro、DeepSeek Chat / R1、通义千问 Max / Plus、智谱 GLM-4 Plus、Kimi 128K、MiniMax、讯飞星火、GPT-4o / 4o Mini、Claude 3.5 Sonnet、Gemini 1.5 Pro、硅基流动开源模型、Ollama 本地模型等。

**图像模型**：豆包 Seedream 4.5 / 3.0、通义万相、Wan 2.7 Image Pro、CogView 3 / 4、Stable Diffusion XL / 3、DALL·E 3、Ideogram V2、Recraft V3、FLUX 1.1 Pro、硅基流动开源图像模型等。

**视频模型**：豆包 Seedance Pro / Lite、可灵 1.5 / 1.6、即梦 V1 / V2、海螺 V1 / V2、MiniMax H3、HappyHorse 1.1、Runway Gen3、Pika 2.0 等。

**音频模型**：豆包 TTS、OpenAI TTS / TTS HD、ElevenLabs、Azure TTS、讯飞 TTS、通义 TTS、Edge TTS（免费）等。

### 2.5 自定义 OpenAI 兼容模型

如果你的模型服务商提供 OpenAI 兼容接口：

1. 选择 Provider 为 `openai`（或对应服务商）
2. 填写 Model Name
3. 填写 API Key
4. 在 Endpoint URL 中填入你的接口地址（如 `https://api.your-service.com/v1`）
5. 测试连接并保存

> **提示**：至少需要配置一个文本模型才能开始使用。图像、视频、音频模型可按需配置。

## 3. 创建项目与上传小说

### 3.1 创建新项目

1. 在仪表盘（首页）点击「**新建项目**」。
2. 填写项目信息：
   - **项目名称**（必填，最多 200 字）
   - **项目描述**（可选，最多 2000 字）
   - **类型 / 题材**（可选）
   - **目标时长**：1min / 3min / 5min / 10min（可选）
   - **语言**（可选）
   - **流水线模式**：`auto`（全自动）或 `semi-auto`（半自动，默认）
   - **风格预设**（可选，后续可改）
3. 点击「**创建**」。

### 3.2 上传小说

创建项目后自动进入「**剧本阶段**」。

1. 点击「**上传小说**」按钮。
2. 选择一个 **TXT 格式**的小说文件。
   - 系统会自动识别章节标题（如"第一章 xxx"、"第1章 xxx"等格式）并拆分章节。
   - 支持中文文件名。
3. 上传成功后，左侧会显示解析出的章节列表。

### 3.3 章节管理

上传后可以对章节进行调整：

- **合并章节**：选中多个章节，点击「合并」，将内容合并到第一个章节。
- **拆分章节**：在章节编辑器中指定拆分位置，将一章拆为两章。
- **编辑章节**：点击章节可直接编辑标题和内容。

## 4. 9 阶段流水线操作

CineSlice Studio 将影视创作分为 **9 个阶段**，按顺序执行：

| 序号 | 阶段 | 英文标识 | 说明 | 使用模型类型 |
|------|------|----------|------|-------------|
| 1 | 小说上传 | `novel` | 上传 TXT 小说，自动解析章节 | — |
| 2 | 剧集拆分 | `episodes` | AI 将小说拆分为若干集，每集含剧本概要 | 文本 |
| 3 | 剧本生成 | `script` | AI 生成每集的完整剧本 | 文本 |
| 4 | 角色设定 | `characters` | AI 从剧本中提取角色，生成角色设定与概念图 | 文本 + 图像 |
| 5 | 场景设定 | `scenes` | AI 从剧本中提取场景，生成场景设定与概念图 | 文本 + 图像 |
| 6 | 分镜生成 | `shots` | AI 将剧本拆分为镜头，含景别、运镜、时长、对话 | 文本 |
| 7 | 关键帧 | `keyframes` | 为每个镜头生成首帧 / 尾帧 / 中间帧图像 | 图像 |
| 8 | 配音生成 | `audio` | TTS 语音合成，生成旁白与角色配音 | 音频 |
| 9 | 视频生成 | `video` | 基于关键帧生成每个镜头的视频片段，最终合成 | 视频 |

### 4.1 阶段 2：剧集拆分

1. 在剧本阶段，确认章节内容无误后，点击「**生成剧集**」。
2. 配置参数：
   - **文本模型**：选择已配置的文本模型
   - **剧集数量**：希望拆成多少集（1-50 集，可选）
   - **风格**：影视风格描述（可选）
3. 点击「**开始生成**」，等待 AI 返回剧集列表。
4. 生成完成后，可查看每集的标题、涵盖章节范围、剧本概要。
5. 可手动编辑剧集标题和剧本内容。

> **提示**：如果剧集数量超过 10 集或小说内容过长，系统会自动分批生成（每批 5 集），请耐心等待。

### 4.2 阶段 3：剧本生成

1. 选择一个剧集，进入剧本编辑器。
2. 点击「**生成剧本**」或「**润色剧本**」。
   - **生成剧本**：基于剧集概要生成完整剧本。
   - **润色剧本**：对已有剧本进行优化润色。
3. 选择文本模型，点击开始。
4. 生成完成后可在编辑器中直接修改。

### 4.3 阶段 4-5：角色与场景设定

进入「**资产阶段**」（左侧边栏切换或顶部标签切换）。

1. 点击「**提取角色**」，AI 自动从剧本中识别所有角色。
2. 每个角色包含：姓名、性别、角色类型（主角/配角/反派/群演）、描述、外貌描述。
3. 点击角色卡片可查看详情，并可：
   - **生成概念图**：选择图像模型，为角色生成多张概念图。
   - **选择参考图**：从生成的概念图中选择一张作为角色标准形象。
   - **创建变体**：为同一角色创建不同造型 / 服装的变体。
4. 场景设定操作类似：点击「**提取场景**」，AI 识别剧本中的场景，生成场景概念图。

### 4.4 阶段 6：分镜生成

1. 在剧本阶段或导演阶段，选择一个剧集。
2. 点击「**生成分镜**」。
3. 配置参数：
   - **文本模型**：用于生成分镜脚本
   - **图像模型**（可选）：同时生成关键帧
   - **分镜密度**：`sparse`（稀疏）/ `normal`（正常）/ `dense`（密集）
   - **包含对话**：是否在分镜中包含对话内容
4. 生成后，每个镜头包含：
   - 镜头编号、景别（特写 / 中景 / 全景 / 远景）
   - 动作描述、对话、运镜方式（固定 / 摇 / 倾 / 推拉 / 变焦）
   - 时长（秒）、涉及角色、涉及道具
   - 可手动编辑任意字段

### 4.5 阶段 7：关键帧

进入「**导演阶段**」。

1. 选择一个镜头，点击「**生成关键帧**」。
2. 配置：
   - **图像模型**
   - **帧类型**：`first`（首帧）/ `last`（尾帧）/ `middle`（中间帧，可多张）
   - **参考角色**：选择该镜头中出现的角色（用于保持角色一致性）
   - **参考场景**：选择该镜头的场景
3. 生成后可预览关键帧图像，不满意可重新生成。

### 4.6 阶段 8：配音生成

1. 在导演阶段，切换到「**音频**」面板。
2. 选择剧集或镜头，点击「**生成配音**」。
3. 配置：
   - **音频模型**：TTS 模型
   - **音色**：选择发音人（如中文女声、中文男声等）
   - **语速**：0.25x - 4x
4. 生成后可播放试听，不满意可更换音色或重新生成。

### 4.7 阶段 9：视频生成与合成

1. 确认关键帧和配音就绪后，进入「**导出阶段**」。
2. 点击「**生成视频**」，为每个镜头生成视频片段（基于首帧 → 尾帧的运动生成）。
3. 视频生成是异步任务，可在任务列表中查看进度。
4. 所有镜头视频生成完成后，点击「**合成视频**」：
   - 系统使用 FFmpeg 将所有镜头片段拼接
   - 自动叠加配音音轨
   - 可选添加字幕
5. 合成完成后，点击「**下载**」保存最终视频。

## 5. 全自动 vs 半自动模式

### 5.1 半自动模式（默认，推荐新手）

每个阶段完成后，系统会暂停并等待你确认：

- 查看 AI 生成结果
- 手动编辑 / 调整
- 确认无误后点击「**下一阶段**」推进

适合对生成质量有要求、希望逐步把控的用户。

### 5.2 全自动模式

启动后 AI 自动依次执行所有 9 个阶段，无需人工干预：

1. 创建项目时选择模式为 `auto`，或在项目设置中切换。
2. 上传小说后，点击「**启动全自动流水线**」。
3. 系统自动执行：剧集拆分 → 剧本 → 角色 → 场景 → 分镜 → 关键帧 → 配音 → 视频。
4. 可在流水线进度面板实时查看当前阶段和状态。
5. 支持**取消**和**恢复**：中断后可从当前阶段继续。

> **注意**：全自动模式会消耗较多 API 调用额度，建议先在小项目上测试。

### 5.3 流水线操作按钮

| 按钮 | 功能 |
|------|------|
| **启动** | 初始化流水线，开始第一阶段 |
| **下一阶段** | 半自动模式下，确认当前阶段并推进到下一阶段 |
| **重试** | 当前阶段失败时，重新执行该阶段 |
| **回退** | 回退到上一阶段（当前及之后阶段重置为待处理） |
| **重置** | 清空整个流水线状态，重新开始 |

## 6. 角色与场景资产管理

### 6.1 角色管理

- **角色卡片**：展示角色姓名、类型、概念图缩略图。
- **角色详情**：点击卡片展开，查看完整描述、外貌描述、所有概念图。
- **四视图**：部分角色支持生成正面 / 侧面 / 背面 / 四分之三视图，用于保持视频中角色一致性。
- **角色变体**：同一角色的不同造型（如便服 / 战损 / 老年版），可在分镜中指定使用哪个变体。

### 6.2 场景管理

- 场景包含：名称、地点、时间（白天/夜晚/黎明/黄昏）、氛围、描述、概念图。
- 可手动添加自定义场景。

### 6.3 道具管理

- AI 自动提取剧本中的道具，分类为：武器 / 家具 / 交通工具 / 其他。
- 可为道具生成概念图。

### 6.4 共享资产库

- 满意的角色 / 场景 / 道具可添加到「**共享资产库**」。
- 资产库中的资产可在其他项目中复用，避免重复生成。

## 7. 关键帧与配音

### 7.1 关键帧类型

| 帧类型 | 说明 | 数量 |
|--------|------|------|
| `first`（首帧） | 镜头开始时的画面 | 每镜头 1 张 |
| `last`（尾帧） | 镜头结束时的画面 | 每镜头 1 张 |
| `middle`（中间帧） | 镜头过程中的关键画面 | 每镜头可多张 |

首帧和尾帧用于视频生成模型的图生视频（Image-to-Video），确保镜头运动有明确的起止画面。

### 7.2 配音类型

- **旁白**：故事叙述性语音，基于剧本描述生成。
- **角色对话**：角色台词，可为不同角色指定不同音色。
- **语速调节**：0.25x（极慢）到 4x（极快），默认 1x。

## 8. 视频合成与导出

### 8.1 视频生成

- 每个镜头基于关键帧（首帧 → 尾帧）生成 3-10 秒的视频片段。
- 视频生成是异步任务，提交后可在「任务中心」查看进度。
- 支持的视频模型包括：豆包 Seedance、可灵、即梦、海螺、MiniMax、HappyHorse、Runway、Pika 等。

### 8.2 视频合成

所有镜头视频生成完成后：

1. 进入「导出阶段」。
2. 点击「**合成视频**」。
3. 系统使用 FFmpeg 执行：
   - 按镜头顺序拼接所有视频片段
   - 混合配音音轨
   - （可选）烧录字幕
   - 输出最终 MP4 文件
4. 合成过程中可查看 FFmpeg 实时日志。

### 8.3 导出与下载

- 合成完成后，视频文件保存在项目的 `outputs/` 目录中。
- 点击「**下载**」保存到本地。
- 支持导出项目数据包（ZIP），包含剧本、角色、分镜、关键帧等所有数据，可在其他设备导入恢复。

## 9. 风格预设

### 9.1 什么是风格预设

风格预设是一组预定义的影视创作参数集合，包括：

- **视觉风格**：整体画面风格描述（如"赛博朋克"、"水墨国风"、"日系动漫"）
- **镜头语言**：运镜偏好、景别偏好
- **色彩 Palette**：主色调、辅助色
- **节奏**：镜头切换节奏（快节奏 / 慢节奏）
- **视频参数**：分辨率、帧率等

### 9.2 使用风格预设

1. 创建项目时选择一个风格预设。
2. 或在项目设置中切换风格预设。
3. 应用后，AI 生成剧本、分镜、关键帧时会自动融入该风格。

### 9.3 内置预设

系统内置多种风格预设（首次启动时自动种子初始化），涵盖：

- 写实电影风
- 动漫 / 二次元风
- 国风水墨
- 赛博朋克
- 复古胶片
- 等等

## 10. 常见问题

### Q1：启动后页面空白？

A：检查终端是否有报错。确保已执行 `npm install` 安装依赖。尝试刷新浏览器（Ctrl+F5 强制刷新）。

### Q2：提示"未收到上传文件"？

A：确保文件是 **TXT 格式**且不为空。如果文件编码不是 UTF-8，请先用记事本另存为 UTF-8 编码。

### Q3：AI 生成返回错误 / 超时？

A：
- 检查 API Key 是否正确、是否有余额。
- 在模型配置页点击「测试连接」验证。
- 小说内容过长时，生成可能需要较长时间，请耐心等待（默认超时 10 分钟）。
- 查看后端终端日志获取详细错误信息。

### Q4：端口被占用怎么办？

A：CineSlice Studio 会自动检测端口占用并尝试释放（Windows 下自动 taskkill），释放不了则自动递增端口号。也可通过环境变量 `VITE_PORT`（前端）和 `PORT`（后端）自定义端口。

### Q5：如何切换本地模式 / 服务端模式？

A：在 `.env` 文件中修改 `RUN_MODE=local` 或 `RUN_MODE=server`，重启服务。服务端模式需要配置强 `JWT_SECRET`。

### Q6：生成的视频在哪里？

A：最终视频保存在项目目录下的 `outputs/` 文件夹中，也可在导出阶段直接点击下载。

### Q7：如何备份项目？

A：在项目设置中点击「导出项目」，下载 ZIP 数据包。在其他设备的项目列表页点击「导入项目」上传该 ZIP 即可恢复。

### Q8：Edge TTS 免费吗？需要 API Key 吗？

A：Edge TTS 基于微软 Edge 浏览器的在线 TTS 服务，**完全免费且无需 API Key**。但需要网络连接微软服务器，且不保证长期稳定性。

### Q9：可以使用本地部署的模型吗？

A：可以。文本模型支持 Ollama 本地部署（选择 Provider 为 `ollama`）。其他类型模型如果提供 OpenAI 兼容接口，可通过自定义 Endpoint URL 接入。

### Q10：全自动流水线中断了怎么办？

A：在流水线面板点击「恢复」，系统会从中断的阶段继续执行。如果是服务器重启导致的中断，重启后系统会自动标记残留任务为失败，可手动重新启动。
